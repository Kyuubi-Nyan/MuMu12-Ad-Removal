# MuMu 桌面去广告脚本

这是一个可撤销的 Windows 防火墙方案，用于拦截 MuMu 桌面广告相关的远程 IP。

## 特点

- 不需要 DataPart。
- 不修改 MuMu 模拟器文件。
- 不修改 hosts。
- 不下载来路不明的 exe。
- 只创建以 `MuMuDesktopAdBlock-Codex-` 开头的防火墙规则。
- 可以通过关闭脚本完整撤销。

## 使用方法

1. 完全退出 MuMu。
2. 右键 `开启桌面去广告.bat`，选择“以管理员身份运行”。
3. 看到“桌面去广告规则已应用”后重新启动 MuMu。
4. 如果游戏中心、虚拟定位、游戏加速、谷歌安装器等功能异常，运行 `关闭桌面去广告.bat` 撤销。

脚本会自动定位 MuMu 安装目录，并查找 `MuMuVMMHeadless.exe`。

## 说明

这个方案对应 MuTools 原项目里的“防火墙禁用连接”思路，原项目将该项标记为“废弃”。它的优点是无需 DataPart、可以撤销；缺点是有可能影响部分在线功能。建议先备份模拟器数据。
