# MuTools 资源包（只需要这两个）

本目录提供 MuTools 所需的两个资源包，不需要 `DataPart` 或 `RuntimeChecker`。

| 文件 | 用途 | 来源 |
| --- | --- | --- |
| `7zip_Win_x86_32bit_26.02.exe` | MuTools 解压 `.7z` 资源包时使用 | 7-Zip 26.02 官方 x86 版 |
| `aria2_Win_x86_32bit_1.37.0_1.exe` | MuTools 下载加速时使用 | aria2 1.37.0 官方 win-32bit build1 |

## 下载

- [7zip_Win_x86_32bit_26.02.exe](./7zip_Win_x86_32bit_26.02.exe)
- [aria2_Win_x86_32bit_1.37.0_1.exe](./aria2_Win_x86_32bit_1.37.0_1.exe)
- [SHA256SUMS.txt](./SHA256SUMS.txt)

## 安装方法

```text
打开 MuTools
→ 资源包管理
→ 安装资源包
→ 本地安装
→ 选择 7zip_Win_x86_32bit_26.02.exe
→ 再安装 aria2_Win_x86_32bit_1.37.0_1.exe
```

安装完成后，资源包管理页面应该能看到：

```text
7zip
aria2
```

## 说明

- 这两个文件足够完成视频里的去广告流程。
- 不要在不明网站下载 `DataPart_1.0.0_4.1.38.exe`、`DataPart_1.0.0_5.30.1.exe` 或 `RuntimeChecker_1.0.0.exe`。
- 使用前建议先备份模拟器中的重要数据。
- 7-Zip 和 aria2 分别遵循各自的官方开源许可证。
